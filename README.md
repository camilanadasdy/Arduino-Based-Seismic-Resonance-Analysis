# Seismic Resonance Analysis

Experimental project focused on studying the vibrational response of a mechanical structure and determining its resonance frequency using an Arduino-based measurement system.

## Objective

The main objective of this project was to analyze the response of a structure to external vibrations and identify its natural resonance frequency through experimental measurements.

## Methodology

The system uses an accelerometer to measure the vibrations produced in the structure under different excitation conditions. The collected measurements are then analyzed to identify the frequency at which the system exhibits its strongest response.

## Hardware

* Arduino
* MPU6050 accelerometer and gyroscope
* Vibration source
* Mechanical structure
* Electronic components

## Software

* Arduino IDE
* C/C++
* Serial data acquisition
* Data analysis

## Results

The experimental measurements were used to characterize the vibrational response of the system and determine its resonance frequency.
